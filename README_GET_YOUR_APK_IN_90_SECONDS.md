# How to Get Your Ready-to-Install `.apk` File (No Android Studio Needed)

Because an `.apk` binary must be compiled and signed by the Android SDK toolchain, this package includes an automated **1-Click GitHub Cloud APK Builder**. You can generate and download the `.apk` directly on your phone or PC in ~90 seconds:

### Step 1: Upload to GitHub
1. Create a new repository on [GitHub](https://github.com/new) (e.g., `tv-ultra-remote`).
2. Extract this `.zip` and upload all files/folders into that repository (or push via Git).

### Step 2: Download Your Compiled `.apk`
1. Click the **Actions** tab at the top of your GitHub repository.
2. Click the running workflow (**Build TV Ultra Remote APK**).
3. Once the green checkmark appears (~90 seconds), scroll down to **Artifacts** and tap **`TV-Ultra-Remote-APK`** to download your ready-to-install `.apk`!
